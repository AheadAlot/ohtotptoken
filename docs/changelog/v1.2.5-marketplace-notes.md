# OTP Token v1.2.5 应用市场更新文案（400字精简版）

---

## 简体中文（约430字）

### 版本亮点
本次更新带来多项新功能与体验优化，让令牌管理更便捷安全。

**新增功能**
- 令牌列表新增长按快捷菜单，支持预览动效，查看详情更直观
- 新增拖拽排序功能，长按即可排序，自由调整令牌顺序
- 新增从其他验证器导入令牌，支持备份文件及链接导入，迁移更轻松
- 新增图标包云备份与跨设备同步，更换设备无忧
- 图标选择全面升级，支持管理多套图标包
- 搜索功能独立成页，查找令牌更快捷
- 验证码改用等宽字体，数字对齐更整齐
- 长按时长支持自定义（200-1000ms）

**体验优化**
- 列表边距优化，浏览更舒适
- 滑动按钮边距可自定义，适配不同手势习惯
- 删除弹窗新增账户名显示，避免误删
- 优化安全区适配，页面展示更完整
- 备份迁移页面布局优化，分区更清晰

**问题修复**
- 修复升级后桌面卡片配置丢失问题
- 修复编辑令牌后界面未及时刷新问题
- 修复重启后偏好设置丢失问题
- 修复宽屏下令牌排序错位问题
- 修复倒计时显示卡顿问题
- 多项安全性与稳定性加固
