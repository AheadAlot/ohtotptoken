# OTP Token v1.2.5 版本更新说明

> 版本号：1.2.5 (build 1002055)  
> 更新起点：1.2.4 (build 1002042)  
> 跨越提交：66 个 commits  
> 仓库迁移：由 SolidFaker 组织迁移至 OHOTP 组织

## 简体中文

### 新增功能

1. **令牌长按菜单**：现已支持在令牌列表长按唤起上下文菜单，包含预览浮起动效与背景模糊效果，为您的使用带来更丰富、更直观的交互体验，满足您在快速查看令牌详情场景下的需求，等您体验。

2. **令牌拖拽排序**：现已支持在令牌列表长按菜单中进入排序模式，通过拖拽自由调整令牌顺序，满足您对令牌排列个性化管理的需求，等您体验。

3. **从其他验证器导入令牌**：现已支持从「2FA 验证器」备份文件及粘贴 `otpauth://` 链接导入令牌，采用可扩展的框架设计，方便后续支持更多来源，满足您在跨应用迁移场景下的需求，期待您的体验和反馈。

4. **图标包云备份与同步**：现已支持图标包的云端备份与跨设备同步功能，内置状态机与降级兼容逻辑，确保您的自定义图标在多设备间安全流转不丢失，等您体验。

5. **图标选择重构与多图标包管理**：图标选择对话框全面重构，现已支持同时管理多套图标包，解决了单图标包功能单一的局限性，等您体验。

6. **搜索功能独立页面**：搜索功能从原页面中独立为专属页面，操作路径更清晰，搜索体验更流畅，等您体验。

7. **验证码等宽字体**：令牌列表验证码区域现已使用等宽字体显示，数字对齐更整齐，识别更快速，等您体验。

8. **长按触发时长自定义**：现已支持在设置中自定义长按触发时长（200-1000ms），默认为 300ms，您可根据个人使用习惯自由调节灵敏度，满足不同操作精度的需求，等您体验。

### 界面优化

1. **布局优化**：现已完成令牌列表默认内边距从 10 调整为 16，解决了列表边缘内容过于拥挤的问题，让日常令牌查看和管理更舒适，核心信息一目了然。

2. **交互操作优化**：现已完成滑动按钮右侧边距改为用户可配置的 `suffix_padding` 值，解决了固定边距无法适应不同用户手势习惯的问题，让滑动操作更顺手更好用。

3. **交互操作优化**：现已完成删除令牌弹窗新增标题与账户名副标题，解决了删除时无法确认目标令牌身份的问题，让令牌管理更安全、更明确。

4. **视觉设计优化**：现已完成备份迁移页面各分组添加标题、导入器间添加分隔线，解决了功能分区不明显的问题，让跨应用迁移场景的操作流程更清晰、更直观。

5. **交互操作优化**：现已完成 URI 导入弹窗改为屏幕居中显示，解决了弹窗位置偏上不符合操作预期的问题，让粘贴导入链接的操作更自然顺手。

6. **视觉设计优化**：现已完成自定义图标添加按钮阴影被截断的修复，解决了图标选择界面视觉效果不完整的问题，让图标管理界面更精致舒适。

7. **布局优化**：现已完成标题栏安全区裁剪优化与设置页 Sheet 顶部安全区裁剪调整，解决了全屏页面内容被系统状态栏遮挡的问题，让页面内容展示更完整，核心功能触手可及。

### Bug 修复

1. **新增偏好设置持久化保障机制**，可帮助您在应用重启后自动恢复全部设置，避免偏好丢失带来的重复配置烦恼，打开「设置」页面即可安心使用，期待您的体验和反馈。

2. **新增令牌编辑安全性增强**，编辑或新增令牌对话框将在 KV 数据库及 ASSET TEE 存储均持久化成功后才关闭，确保令牌数据不丢失，期待您的体验和反馈。

3. **新增跨设备同步错误恢复机制**，同步失败时自动重置加载状态并提示用户，避免界面卡死在加载中状态，期待您的体验和反馈。

4. **修复应用升级后卡片配置丢失的问题**，确保桌面小组件在版本升级后稳定可用。

5. **修复首次配置卡片时令牌列表为空的问题**，确保新用户首次设置卡片后令牌正常展示。

6. **修复令牌编辑时扫码覆盖密钥后 UI 不刷新的问题**，确保令牌编辑后即时呈现最新状态。

7. **修复兜底计时器每 2 秒才广播一次导致的列表卡顿问题**，确保令牌倒计时显示流畅丝滑。

8. **修复宽屏下排序页令牌错位问题**，确保大屏设备上令牌排序操作位置准确。

9. **修复应用重启后全部偏好设置丢失的严重问题**，确保应用设置稳定持久化。

10. **修复硬编码 IV 与零值 PBKDF2 盐的安全问题**，替换为按文件随机生成，显著提升加密存储安全性。

### 性能优化

1. 令牌列表新增 `cachedCount` 预加载优化，列表滚动更流畅。
2. 图标包备份/还原中的同步文件 I/O 改为异步操作，避免主线程阻塞。
3. 冷启动新增 hiTraceMeter 链路追踪与 `ASSET_MIGRATION_DONE` 标记，启动速度可观测且更可控。
4. 长按响应时间由 500ms 缩短至 200ms，菜单呼出更敏捷。
5. 拆分 `saveToken` 逻辑，避免 `updateTokenRank` / `deleteToken` 中不必要的 ASSET TEE 调用，提升高频操作性能。

### 其他

- GitHub 仓库由 SolidFaker 组织全面迁移至 OHOTP 组织，项目持续维护有保障。
- 更新 README 截图为手机/PC 分类展示，同步功能清单至最新版本。

## English

### New Features

1. **Token Context Menu**: Long press on any token in the list to invoke a context menu with preview animation and background blur effects, bringing a richer and more intuitive interaction experience. Perfect for quickly inspecting token details at a glance.

2. **Token Drag-and-Drop Sorting**: Enter sort mode from the long-press context menu and freely reorder tokens by dragging. Empowers you to personalize token arrangement to match your workflow.

3. **Import Tokens from Other Authenticators**: Import tokens from "2FA Authenticator" backup files or by pasting `otpauth://` links. Built on an extensible framework to support more sources in the future, making cross-app migration seamless.

4. **Icon Pack Cloud Backup & Sync**: Backup and sync your custom icon packs across devices with a built-in state machine and fallback compatibility. Your carefully curated icons stay safe and consistent everywhere.

5. **Revamped Icon Selection & Multi-Pack Management**: The icon picker dialog has been completely redesigned to support managing multiple icon packs simultaneously, breaking free from the limitations of a single pack.

6. **Dedicated Search Page**: Search functionality has been extracted into its own dedicated page for clearer navigation and a smoother search experience.

7. **Monospace Font for Verification Codes**: Verification codes in the token list now use a monospace font, ensuring digits align perfectly for faster and more accurate reading.

8. **Customizable Long Press Duration**: Adjust the long press trigger duration in settings (200–1000ms, default 300ms) to match your personal preference and operating precision.

### UI/UX Improvements

1. **Layout Optimization**: Default token list padding increased from 10 to 16, eliminating cramped edges and making everyday token browsing and management more comfortable. Core information is now clearly presented.

2. **Interaction Optimization**: Slide button right margin is now user-configurable via the `suffix_padding` value, replacing the fixed margin that couldn't accommodate different gesture habits. Swipe actions feel more natural and responsive.

3. **Interaction Optimization**: The delete token dialog now shows a title and the account name as subtitle, solving the problem of not knowing which token is being deleted. Token management is now safer and clearer.

4. **Visual Design Optimization**: Backup & migration page now features section titles and dividers between importers, making functional areas distinct and the cross-app migration workflow more intuitive.

5. **Interaction Optimization**: The URI import dialog now appears centered on screen instead of offset upward, making the paste-import operation feel more natural and easier to use.

6. **Visual Design Optimization**: Fixed the shadow clipping issue on the custom icon add button, restoring the complete visual effect of the icon picker interface for a more polished experience.

7. **Layout Optimization**: Optimized title bar safe area clipping and adjusted the settings sheet top safe area, preventing content from being obscured by the system status bar. Page content now displays fully with core features easily accessible.

### Bug Fixes

1. **Added preference persistence guarantee** — automatically restores all settings after app restart, eliminating the frustration of lost preferences. Simply open the Settings page and use with confidence.

2. **Enhanced token editing safety** — the edit/new token dialog now waits for both KV database and ASSET TEE storage to confirm persistence before closing, ensuring no token data is lost.

3. **Added cross-device sync error recovery** — automatically resets the loading state and notifies the user when sync fails, preventing the UI from being stuck in a perpetual loading state.

4. **Fixed card configuration loss after app update**, ensuring desktop widgets remain stable and functional after version upgrades.

5. **Fixed empty token list on first card configuration**, ensuring new users see their tokens correctly after initial card setup.

6. **Fixed UI not refreshing after scanning to overwrite key during token editing**, ensuring the latest state is displayed immediately after editing.

7. **Fixed list stutter caused by fallback timer broadcasting only every 2 seconds**, ensuring the countdown display runs smoothly and seamlessly.

8. **Fixed token misalignment on the sort page in wide-screen mode**, ensuring accurate drag-and-drop positioning on larger displays.

9. **Fixed critical issue of all preferences being lost after app restart**, ensuring stable and persistent app settings.

10. **Fixed security issue with hardcoded IV and zero-value PBKDF2 salt**, replaced with per-file random generation for significantly enhanced encrypted storage security.

### Performance Improvements

1. Added `cachedCount` preloading optimization for smoother token list scrolling.
2. Converted synchronous file I/O in icon pack backup/restore to asynchronous operations, preventing main thread blocking.
3. Added hiTraceMeter tracing and `ASSET_MIGRATION_DONE` flag for cold start, making startup speed observable and more predictable.
4. Reduced long press response time from 500ms to 200ms for snappier menu invocation.
5. Split `saveToken` logic to eliminate unnecessary ASSET TEE calls in `updateTokenRank`/`deleteToken`, boosting performance for frequent operations.

### Miscellaneous

- GitHub repository migrated from the SolidFaker organization to OHOTP for continued project maintenance.
- Updated README screenshots with phone/PC categories and synchronized the feature list to the latest version.
